    73→    73→1. Executive Summary
    74→    74→Free Programs Pro Store is a multi-platform software marketplace and app store where an administrator and authorized developers publish free programs for Windows, Linux/Ubuntu, Android, and Chrome Extensions. The public site is a browse-and-download storefront with a Play Store-style experience. A private admin panel handles app creation, version management, binary uploads, malware scanning, publication, and analytics.
    75→    75→
    76→    76→The product is delivered as:
    77→    77→
    78→    78→A web storefront (public)
    79→    79→
    80→    80→An admin panel (private)
    81→    81→
    82→    82→A Progressive Web App installable on phones, tablets, and desktops
    83→    83→
    84→    84→It is not a general-purpose app store for third-party developers. It is a curated, admin-controlled catalog, with optional future support for external uploader accounts under moderation.
    85→    85→
    86→    86→2. Vision & Goals
    87→    87→Vision
    88→    88→Become the cleanest, most trustworthy place to discover and download free software across desktop, mobile, and browser — with transparent checksums, verified files, and no piracy.
    89→    89→
    90→    90→Primary Goals
    91→    91→Let an admin upload, version, and publish apps across four platforms in under 5 minutes per app.
    92→    92→
    93→    93→Give visitors a Play Store-quality browsing experience on phone and desktop.
    94→    94→
    95→    95→Establish trust through checksums, scan status, licensing, and source URLs.
    96→    96→
    97→    97→Be installable as a PWA on every major platform.
    98→    98→
    99→    99→Achieve Lighthouse ≥ 95 (mobile) on public pages.
   100→   100→
   101→   101→Success Metrics (first 6 months)
   102→   102→Metric  Target
   103→   103→Apps published  100+
   104→   104→Monthly downloads       50K
   105→   105→PWA install rate        ≥ 3% of returning visitors
   106→   106→Bounce on app detail    ≤ 40%
   107→   107→Median LCP (mobile)     < 2.0s
   108→   108→Admin publish time      < 5 min/app
   109→   109→3. Non-Goals
   110→   110→Not a paid app store (v1). Donations/Pro membership are optional add-ons.
   111→   111→
   112→   112→Not a piracy or warez host. Only apps the operator owns or is licensed to distribute.
   113→   113→
   114→   114→Not a developer SDK marketplace in v1.
   115→   115→
   116→   116→Not a code signing service.
   117→   117→
   118→   118→Not a replacement for GitHub Releases for source distribution.
   119→   119→
   120→   120→Not a desktop-native installer framework.
   121→   121→
   122→   122→4. Target Users & Personas
   123→   123→Persona A — Sam, casual visitor (mobile)
   124→   124→Wants a free PDF tool for Android. Lands from Google. Wants to find it, trust it, download it, in under 60 seconds. Cares about ratings, size, and "is it safe?"
   125→   125→
   126→   126→Persona B — Priya, power user (desktop)
   127→   127→Needs a specific Linux .deb. Cares about architecture (amd64/arm64), distro, dependency notes, checksum, and version history. Will verify SHA-256 before installing.
   128→   128→
   129→   129→Persona C — Marco, uploader (future role)
   130→   130→Has built a Chrome extension. Wants to submit it for review. Needs a submission portal, status updates, and version management.
   131→   131→
   132→   132→Persona D — The Admin (primary operator)
   133→   133→Owns the site. Uploads everything. Needs a fast, reliable dashboard: create app → upload files → set versions → publish. Wants analytics, moderation queues, and audit logs.
   134→   134→
   135→   135→Persona E — Moderator
   136→   136→Handles user reports, review moderation, takedown requests. Needs a queue-first UI.

   217→   217→7. Design System
   218→   218→7.1 Design Principles
   219→   219→Principle       Description
   220→   220→Content-first   Icon, name, rating, badge do the work. Chrome stays quiet.
   221→   221→One primary action      Every card/detail has one loud button: Download.
   222→   222→Scannable       20 apps glanceable in 3 seconds. Consistent card anatomy.
   223→   223→Progressive disclosure  Summary first, expandable detail.
   224→   224→Two shapes, one product Phone and desktop are the same product, different shells.
   225→   225→Feels native    Installable PWA, safe-area aware, 60fps scroll.
